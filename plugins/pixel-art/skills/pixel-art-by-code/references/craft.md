## 1. 调色板与色阶

- 每种材质（皮肤、衣服、金属、头发……）用 3~5 阶，从暗到亮。生成方法是 `P.ramp(base, 5)`，它返回 `[深阴影, 阴影, 底色, 亮面, 高光]`。
- **色相偏移**：暗部往蓝紫偏，亮部往黄偏；暗部饱和度稍高，亮部稍低。这样色阶有冷暖变化，比单纯调亮暗更生动。`P.ramp` 默认就这么做，可以用 `hueShift`、`valStep`、`satStep` 调节。
- **不同材质之间相邻的颜色**，要拉开明度差。否则缩小以后会糊成一片。
- **描边色**：用偏冷的近黑色（例如 `#1d1b2e`），比纯黑柔和。
- **控制总色数**：小角色 8~16 色，场景 16~32 色。用 `pixel.js stats` 检查。颜色越少，越像像素画。

## 2. 描边

- **全描边**：`s.outline(暗色)`，在不透明区域外围加一圈 1 像素描边。可读性最好，放在任何背景上都清楚。这是默认选择。
- **8 邻域描边**：`s.outline(c, { diagonal: true })`，斜角也补齐，轮廓更粗、更圆。
- **选择性描边（sel-out）**：描边颜色跟随它挨着的填充色变化。亮面一侧用较浅的描边，暗面一侧用较深的。效果更柔和，适合较大的立绘：

  ```js
  const line = P.c('#1d1b2e');
  s.outline(line);
  const src = s.px.slice();
  for (let y = 0; y < s.h; y++) for (let x = 0; x < s.w; x++) {
    if (src[y * s.w + x] !== line) continue;
    // 取右边或下边的填充色（光从左上来，所以左上方的描边挨着的是亮面）
    const n = [[1, 0], [0, 1], [-1, 0], [0, -1]]
      .map(([dx, dy]) => s.get(x + dx, y + dy))
      .find((k) => k >>> 24 && k !== line);
    if (n) s.set(x, y, P.mix(n, line, x < s.w / 2 && y < s.h / 2 ? 0.45 : 0.7));
  }
  ```

- **内部分界线**：不同部件之间（手臂和身体、衣服和皮肤）画 1 像素的暗线，或者用阴影色，帮助区分层次。

## 3. 打光

- 光源固定在左上。`s.rim(hi, sh, { depth, group })`：
  - 上边和左边缘的像素换成 `hi(c)`，下边和右边缘（深 `depth` 像素）换成 `sh(c)`；
  - `hi` / `sh` 可以是函数、`{ '#底色': '#亮色' }` 这样的映射表，或单一颜色；
  - `group(c)` 返回材质名，不同组之间互相算作“外部”，各自打光。
- **顺序很重要**：剪影 → 打光 → 内部细节 → 描边 → 五官。内部细节如果在打光之前画，会被当成“洞”，周围出现一圈阴影。
- **不要做“枕头阴影”**，也就是四周一圈都压暗、中间亮。光有方向，阴影只出现在背光的一侧。
- **接触阴影**：两个部件重叠或接触的地方（腋下、脖子下、脚底），多压暗一阶。
- **高光**：要小、要少。1~3 个像素放在最亮的位置（左上），就足以表现光泽。

## 4. 抖动

- **适合用的地方**：大面积渐变（天空、背景墙）、半透明效果（阴影、光晕、聚光灯）、粗糙材质。
- **不适合用的地方**：小角色身上的明暗。在小尺寸上抖动只会变成噪点，用色阶就好。
- 用法：
  - `s.dither(x, y, w, h, c, alpha)` 和 `s.ditherEllipse(...)`：按 Bayer 4×4 网点，以透明度 alpha 盖一层颜色；
  - `s.gradient(x, y, w, h, [c0, c1, c2])`：分段渐变，交界处自动抖动；
  - 50% 的棋盘格是最经典的两色混合。

## 5. 线条与曲线

- **用 `s.line`（Bresenham）**：每一步只走 1 个像素，不会出现 L 形的双像素台阶。
- **斜线的步长要规律**：常用的比例有 1:1、1:2、2:1、1:3，例如每 2 格横移 1 格。不规则的步长（3,1,2）会显得毛糙。
- **曲线**：由逐渐变化的线段组成，例如 4-3-2-1-1-2-3-4，两侧对称。
- **清理孤点和双像素**：画完把图打印成字符（`ascii`）看一遍，L 形拐角和孤立像素会很显眼。

## 6. 小圆：直接用字符画

直径 8 像素以内的圆，用 `ellipse` 容易画成方块或歪斜，直接用下面这些标准形状：

```
d3      d4       d5        d6         d7          d8
.#.     .##.     .###.     ..##..     ..###..     ..####..
###     ####     #####     .####.     .#####.     .######.
.#.     ####     #####     ######     #######     ########
        .##.     #####     ######     #######     ########
                 .###.     .####.     #######     ########
                           ..##..     .#####.     ########
                                      ..###..     .######.
                                                  ..####..
```

用法：`s.stamp(['.##.', '####', '####', '.##.'], { '#': 色 }, x, y)`。

## 7. 五官与特效库

下面的尺寸以 32 px 左右的角色为准，可以直接复制。调色板约定：`o` 线条色、`w` 白、`t` 舌头、`m` 口腔、`b` 浅蓝、`d` 深蓝、`v` 红、`s` 淡黄、`h` 粉、`z` 白。

**眼睛**（这里只给左眼，右眼用 `{ flip: true }` 镜像）：

| 名称 | 字符画 | 用于 |
|---|---|---|
| 圆点 | `['wo', 'oo', 'oo']` | 默认，左上角是高光 |
| 弯眼 ^ | `['.o.', 'o.o']` | 开心、笑 |
| 闭眼 | `['ooo']` | 眨眼、困、满足 |
| 白眼 | `['www', 'wow', 'www']` | 惊吓 |
| 星星眼 | `['.o.', 'owo', '.o.']` | 兴奋、憧憬 |
| 心形眼 | `['h.h', 'hhh', '.h.']` | 喜欢 |
| 半眯眼 | `['ooo', 'wo.', 'oo.']` | 得意、怀疑 |

**眉毛**（在眼睛上方 2~3 像素）：

| 名称 | 字符画 | 说明 |
|---|---|---|
| 难过 | `['..o', 'oo.']` | 内侧高 |
| 生气 | `['oo.', '..o']` | 内侧低 |

**嘴**（居中放置）：

| 名称 | 字符画 |
|---|---|
| 微笑 | `['o..o', '.oo.']` |
| 张嘴 | `['oooo', 'otto', '.oo.']` |
| 难过 | `['.oo.', 'o..o']` |
| 平 | `['oo']` |
| O 形 | `['.oo.', 'ommo', '.oo.']` |
| 波浪（紧张） | `['o.o.', '.o.o']` |
| 猫嘴 ω | `['o.o.o', '.o.o.']` |
| 露齿笑 | `['oooooo', 'owwwwo', '.oooo.']` |

**特效**（放在头顶或侧上方）：

| 名称 | 字符画 |
|---|---|
| 汗滴 | `['..d..', '.dbd.', '.dbd.', 'dbwbd', 'dbbbd', '.ddd.']` |
| 怒筋 | `['.v.v.', 'vv.vv', '.....', 'vv.vv', '.v.v.']` |
| 闪光 | `['..s..', '..s..', 'sssss', '..s..', '..s..']` |
| 爱心 | `['.h.h.', 'hhhhh', 'hhhhh', '.hhh.', '..h..']` |
| 睡觉 Z | `['zzzz', '..z.', '.z..', 'zzzz']` |
| 感叹号 | `['o', 'o', 'o', '.', 'o']` |
| 问号 | `['ooo', '..o', '.o.', '...', '.o.']` |

另外两个常用效果：
- **眼泪**：在眼睛下方竖着画 1×3 的浅蓝色。
- **腮红**：在眼睛下外侧画 2×1 的粉色。

更大的角色，可以把这些图案按 2 倍重新设计。不要直接放大：放大后线条变粗，和其他部分的风格对不上。

## 8. 可读性检查

- **剪影测试**：把所有不透明像素涂黑，看外轮廓还能不能认出是什么：

  ```js
  const sil = s.copy();
  for (let i = 0; i < sil.px.length; i++) if (sil.px[i] >>> 24) sil.px[i] = P.c('#000');
  sil.save('silhouette.png', { scale: 6 });
  ```

- **原尺寸检查**：最后一定要按 1 倍看一次，比如联系表用 `scale: 1` 再保存一份。很多在放大图里看着不错的细节，原尺寸下会糊成一团。
- **眼睛优先**：眼睛是全图对比度最高的地方（最暗或最亮）。表情主要靠眼睛和眉毛表达，嘴是辅助。
- **细节少而夸张**：小尺寸里放不下所有特征，只保留最有辨识度的两三个，并且画得夸张一些。

## 9. 比例

- **Q 版小角色**（16~32 px）：头部占身高的一半以上，眼睛大，四肢简化成短块。
- **立绘**（64 px 以上）：比例可以更写实，但五官仍然要比真实比例大。
- **差分保持一致**：所有差分同一画布、同一锚点、同一套部件。最后用联系表并排检查，确认没有跳动。
