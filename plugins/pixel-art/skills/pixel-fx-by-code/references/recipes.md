## 1. 生成器参数

参数都在 `scripts/explosion.js` 开头的 `EXPLOSION` 里。约定如下：
- 长度单位是像素，会乘以 `--scale`；
- 时间单位是秒；
- `[a, b]` 表示每个元素从 a 到 b 之间随机取一个值。

**全局**

| 参数 | 含义 | 默认 |
|---|---|---|
| `canvas`、`center` | 画布大小、爆炸中心。中心偏下，给烟留空间 | [64, 80]、[32, 52] |
| `fps` | 采样帧率。所有运动都按秒计算，改帧率只会改变采样密度 | 15 |
| `duration` | `'auto'`：渲染到所有元素消失为止；也可以写秒数 | 'auto' |
| `seed` | 随机种子 | 7 |
| `drag` | 烟团受到的阻力（每秒）。越大，炸开以后停得越快 | 5 |

**颜色**

| 参数 | 含义 |
|---|---|
| `fire` | 火的色阶，从热到冷 7 种。也用于火花、余烬、闪光 |
| `heat` | 与 `fire` 一一对应的热度门槛：烟团的热度不低于第 i 个门槛，就用第 i 种颜色 |
| `smoke` | 烟的 4 种颜色，从亮到暗 |
| `freshSmoke` | 热度高于这个值的烟用暗的三种（新烟），低于它用亮的三种（旧烟） |
| `ringColours` | 冲击波的外圈色、内圈色 |
| `sparkColours` | 火花按年龄依次使用的 4 种火色（`fire` 的下标） |
| `outline` | 默认 `null`。设成一个深色（如 `'#2b2f6b'`），会给烟团层加 1 像素描边。浅色特效放在亮背景上必须加 |

**闪光 `flash`**

| 参数 | 含义 |
|---|---|
| `star` | 星形闪光：`ray` 左右和上方的光芒长度，`down` 下方光芒长度，`diag` 斜向光芒长度，`core` 中心圆半径 |
| `starUntil` | 星形显示到第几秒 |
| `disc`、`discY` | 白色整圆的半径、相对中心的竖直偏移 |
| `discUntil` | 整圆显示到第几秒 |

**冲击波 `ring`**

| 参数 | 含义 |
|---|---|
| `start`、`dur` | 开始时间、持续时间 |
| `r0`、`r1` | 起始半径、最终半径（按 outCubic 先快后慢地扩大） |
| `thick2` | 进度在这个比例之前，环宽 2 像素，之后 1 像素 |
| `squash`、`dy` | 竖直压扁比例、竖直偏移。地面冲击波用 0.35 和 14 |

**烟团**：`core`（核心，1 个）、`puffs`（火球）、`column`（烟柱）

| 参数 | 含义 |
|---|---|
| `n` | 个数 |
| `jitter` | 分层抽样时，每份里随机偏移的比例（0~1） |
| `arc` | 方向范围，默认整圈；`[π, 2π]` 是上半圈 |
| `offset` | 出生位置离中心的距离 |
| `speed`、`squash` | 初速度；竖直速度的压缩比例（0.8 表示火球略扁） |
| `spread`、`lift` | 只用于烟柱：方向在正上方左右展开的角度；出生位置上移的距离 |
| `buoy` | 浮力（像素/秒²）。终速约为 buoy / drag |
| `t0` | 出生时间 |
| `r`、`grow` | 最大半径；长到最大用的秒数 |
| `heat`、`tau` | 初始热度；冷却时间常数。tau 越大，火持续得越久 |
| `life` | 寿命（秒） |
| `z` | 绘制顺序，越大越靠前，生成后不变 |

**寿命曲线 `life`**（所有烟团共用）

| 参数 | 含义 | 默认 |
|---|---|---|
| `hold` | 开头保持满热度的时间 | 0.05 |
| `expand` | 长到最大以后，每秒继续变大的比例 | 0.4 |
| `shrink`、`shrinkFrom` | 末尾收缩的比例；从寿命的多少开始收缩 | 0.75、0.6 |
| `eatFrom`、`eatTo` | 从寿命的多少开始被咬、到多少咬完 | 0.45、0.95 |
| `eatDir`、`eatSpread` | 咬的方向（π/2 = 从下方），以及每个烟团的随机偏差 | π/2、1.6 |
| `eatSize` | 咬圆的最大半径（以烟团半径为单位） | 1.2 |

**火花 `sparks`**：`n`、`jitter`、`speed`、`squash`、`lift`（整体向上的初速度）、`t0`、`life`、`drag`、`grav`（重力）、`trail`（拖尾长度，单位是秒：画出 trail 秒前到现在走过的线段）。

**余烬 `embers`**：`n`、`spreadX`、`spreadY`（出生范围）、`lift`、`rise`（上升速度）、`t0`、`life`、`wobble`（左右摆动幅度）、`blink`（每几帧暗一帧）。

## 2. 4 个预设

| 预设 | 画布 / 帧率 | 和默认爆炸的区别 | 用途 |
|---|---|---|---|
| `explosion` | 64×80，15 fps | — | 爆炸、炮弹、敌人被击毁 |
| `magic` | 64×80，15 fps | 白 → 青 → 紫的配色，默认带深蓝描边；浮力小，烟飘得慢；火花几乎不受重力；余烬更多、更慢；烟柱只有 3 个 | 魔法爆发、技能命中、传送 |
| `dust` | 72×40，15 fps | 没有火（热度 0）；没有闪光、冲击波、火花、余烬；只往上半圈喷，竖直速度压到 0.35 | 落地、冲刺、脚步扬尘 |
| `hit` | 32×32，20 fps | 没有烟团；小星形 → 小白圆 → 冲击波 + 10 个快速火花，约 0.3 秒 | 攻击命中、子弹打在墙上 |

4 个预设都跑过，看过联系表和三种背景；默认爆炸另外试过 3 个随机种子和 0.5、2 倍大小。

magic 的白色和青色在亮背景上几乎看不见，所以它默认带了描边。dust 和 hit 在三种背景上都能看清。

## 3. 调参：想要什么就改什么

| 想要 | 改什么 | 注意 |
|---|---|---|
| 火球更大、更猛 | `puffs.speed` 和 `puffs.r` 调大 | 看 `edge` 列，别被画布切掉 |
| 火烧得更久 | `puffs.tau`、`core.tau` 调大 | 整体变慢；想要层次，tau 的范围要拉开 |
| 冷却层次更丰富 | 拉开 `puffs.tau` 的范围 | 范围太窄，所有烟团会一起变色 |
| 烟飘得更高 | `buoy` 调大，画布加高 | 中心跟着下移 |
| 结束得更快 | `life` 调小 | — |
| 换配色 | `fire`、`smoke`、`ringColours` | 相邻两档的明度要拉开；看亮背景 |
| 放在亮背景上 | `--set outline=#2b2f6b` | 浅色配色必须加；暗背景上描边看不出来，所以没有坏处 |
| 更大的爆炸 | `--scale 2`，再把烟团数量加倍、半径只放大约 1.3 倍 | 实测命令见 SKILL.md |
| 更小的爆炸 | `--scale 0.5` | 24×31，1 倍下仍能认出各阶段 |
| 地面爆炸 | `ring.squash=0.35`、`ring.dy=14` | 只压扁不下移，冲击波会藏在火球后面 |
| 不要某个部分 | `--set ring=null`（或 `flash`、`sparks`、`embers`、`column`、`core`） | — |
| 不一样的形状 | `--seed` 换几个，挑一个 | 每个种子都要看 |
| 慢动作 | `fps` 调高 | 帧数随之增加，GIF 变长 |

## 4. 命令行改参数：--set

```bash
node scripts/explosion.js out/x --set puffs.n=16                 # 数字
node scripts/explosion.js out/x --set "puffs.r=[4,7]"            # 数组要加引号
node scripts/explosion.js out/x --set ring=null --set embers=null # 关掉部分
node scripts/explosion.js out/x --preset magic --set sparks.n=40 # 先选预设，再覆盖
node scripts/explosion.js out/x --set outline=#2b2f6b            # 字符串可以不加引号
```

`--set` 的值按 JSON 解析，解析失败就当作字符串。路径用点号分隔，可以重复使用多次。预设里已经关掉（null）的部分，不能用 `--set` 只开一个子参数，要在 `explosion.js` 里补全那一组参数。

## 5. 写一个新的特效

和 4 个预设都不像的特效，从 `scripts/template.js` 开始写。它是一个不到 60 行的完整例子：物体消失时冒出一团烟，再闪几颗星。结构固定为三段：

1. **生成元素**：用 `FX.rng(seed)` 生成随机数，方向用 `FX.stratified`，范围用 `FX.between`。每个元素记下出生时间 `t0` 和寿命 `life`。
2. **render(t)**：每个元素用 `u = t − t0` 算出状态（位置用 `FX.integrate`，半径和咬的进度用 `FX.smooth`），画到各自的层上：
   - 烟团层先 `FX.clean`；
   - 描边要加在副本上（`cloud.copy().outline(颜色)`），因为检查时只统计清理后的烟团层；
   - 1 像素的元素（星星、火花）在清理之后再画。
3. **渲染、检查、导出**：一直渲染到所有元素消失，然后依次调用：
   - `FX.trim` 去掉首尾空帧；
   - `FX.report` 打印数字；
   - `FX.exportAll` 写出精灵表、JSON、GIF 和三张检查图。

`template.js` 的白烟一开始在亮背景上看不见，加了一圈深色描边才解决。浅色特效（白烟、冰、光）都要这样检查。

## 6. fx.js 函数

| 函数 | 作用 |
|---|---|
| `rng(seed)` | mulberry32 随机数，返回 0~1 |
| `between(rnd, [a, b])` | a 到 b 之间的随机数；传入单个数字时原样返回 |
| `stratified(i, n, rnd, { jitter, arc })` | 第 i 个元素的方向（分层抽样） |
| `noise2(x, y, seed)` | 平滑值噪声，0~1（可用于火焰抖动、湍流） |
| `clamp`、`smooth(a, b, x)`、`ease.outCubic / inCubic / outBack` | 时间曲线 |
| `integrate(body, u, { drag, buoy, grav, dt })` | 固定步长积分，返回 u 秒后的位置 |
| `ballistic(body, u, { drag, grav })` | 闭式解，适合火花 |
| `puff(s, x, y, r, [亮, 底, 暗], { eat, eatDir, eatSize })` | 平涂烟团；半径小于 3 像素时只用底色 |
| `ring(s, cx, cy, R, 宽度, [外, 内], 不透明度, { squash })` | 用 Bayer 抖动淡出的双色环 |
| `star(s, cx, cy, { ray, down, diag, core }, 光芒色, 中心色)` | 星形闪光 |
| `disc(s, cx, cy, r, 边色, 填充色)` | 带 1 像素边的整圆 |
| `clean(层, { open, minIsland, minHole, lonely })` | 开运算 → 去掉小于 6 像素的碎块 → 填上小于 4 像素的洞 → 消孤点 |
| `metrics(帧, { layer, groups })`、`report(帧数组, { layers, groups })` | 每帧的数字；有帧贴边时打印 WARNING |
| `trim(帧数组, 层数组)` | 去掉首尾空帧 |
| `unionCrop(帧数组, 外扩像素)` | 所有帧按并集包围盒统一裁剪 |
| `exportAll(目录, 名字, 帧数组, { fps, anchor, bg, scale, hold, pick, crop, loop })` | 写出全部交付文件和检查图 |
