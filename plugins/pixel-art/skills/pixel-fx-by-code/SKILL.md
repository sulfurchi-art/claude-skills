# 用代码做像素特效

爆炸、烟、魔法、受击火花这类特效，不要一帧一帧地画。特效的每一帧都是同一套规则在不同时刻的结果，所以：

1. **写规则**：把特效拆成几种元素（烟团、火花、冲击波、闪光、余烬），写出它们怎么生成、怎么运动、怎么随时间变色；
2. **算每一帧**：按时间算出每个元素的状态，分层画出来；
3. **先看数字，再看图**：每帧的覆盖面积、贴边像素、孤点数能先排除一批问题；风格问题只能看图（联系表、三种背景、1 倍大小）；
4. **改参数，重跑**：把看到的问题写成具体的修改，改几个数字，再渲染。

做这个技能里的爆炸，前后迭代了 8 版，关键问题几乎都是看图看出来的，过程见 `references/explosion-case.md`。

工具都在 `scripts/` 里，只需要 Node.js 16 以上，没有其他依赖：
- `explosion.js`：现成的生成器，有 4 个预设；
- `template.js`：从零写一个特效的最小例子，可以复制来改；
- `fx.js`：特效函数库；
- `pixel.js`：底层绘图库，和 pixel-art-by-code 技能里的是同一个文件。

## 快速开始

```bash
node scripts/explosion.js out/boom                        # 爆炸（默认）
node scripts/explosion.js out/magic --preset magic        # 魔法爆发：白 → 青 → 紫
node scripts/explosion.js out/dust --preset dust          # 落地烟尘：没有火，贴地横向散开
node scripts/explosion.js out/hit --preset hit            # 受击火花：32×32，20 fps
node scripts/explosion.js out/b3 --seed 3                 # 换一个随机种子
node scripts/explosion.js out/x --set puffs.n=16 --set ring=null    # 改任意参数；null 关掉一个部分
node scripts/template.js out/poof                         # 最小例子：物体消失时的一团烟
```

每次运行都会打印每帧一行数字，并写出这些文件：

| 文件 | 用途 |
|---|---|
| `sheet.png` | 编号联系表（3 倍），逐帧看 |
| `backgrounds.png` | 同几帧分别放在暗、中、亮三种背景上 |
| `sizes.png` | 1 倍和 2 倍，即游戏里的真实大小 |
| `<名字>.gif` | 预览动画（6 倍，末尾空 0.5 秒） |
| `<名字>_sheet.png`、`.json` | 交付用的 1 倍横排精灵表；JSON 里有帧尺寸、帧数、fps、每帧时长、锚点 |
| `frames/` | 1 倍透明单帧 |

用户要“一个爆炸”时，先跑默认预设，看图，再按要求改参数（颜色、大小、时长、元素）。如果要的效果和 4 个预设都不像，就复制一个预设来改，或者从 `template.js` 开始写。

## 工作流程

### 1. 定规格

- **画布和中心**：烟会往上飘，中心要放在画布偏下的位置（爆炸用 64×80，中心 (32, 52)）。多出来的空白导出时会自动裁掉。
- **帧率和时长**：
  - 爆炸 12~15 fps、1~1.4 秒；受击火花 20 fps、约 0.3 秒。
  - 时长不用手算：生成器会一直渲染到所有元素都消失，再去掉首尾的空帧。手定时长时，最后一帧往往还剩一片烟，然后一下子消失。
- **阶段**（以爆炸为例，15 fps）：

  | 阶段 | 帧 | 要点 |
  |---|---|---|
  | 闪光 | 0~1 | 第 0 帧是星形；第 1 帧画一个干净的白色整圆，盖住还没长齐的烟团 |
  | 火球 | 2~4 | 2~3 帧内长到最大，先快后慢 |
  | 冷却 | 5~8 | 每个烟团各自从黄变橙、变红、变暗 |
  | 烟 | 8~12 | 深色的烟往上飘，余烬闪烁 |
  | 消散 | 13~17 | 烟团缩小，从一侧被“咬”成月牙，最后消失 |

- **调色板**：
  - 火 6~7 档：白 → 浅黄 → 黄橙 → 橙 → 红 → 暗红 → 深紫红；
  - 烟 4 档，偏冷的灰紫；
  - 总共十几种颜色。相邻两档的明度要拉开，否则冷却过程看不清。

### 2. 拆成元素

| 元素 | 作用 | 绘制层（1 最底） |
|---|---|---|
| 冲击波 | 一圈快速扩大、用抖动淡出的环 | 1 |
| 火花 | 带拖尾的小线段，有重力 | 2：在烟团后面，飞出火球以后才看得见 |
| 烟团 | 主体。火球和烟都是烟团，只是温度不同 | 3：单独一层，画完做清理 |
| 余烬 | 1 像素的亮点，往上飘，隔几帧暗一下 | 4 |
| 闪光 | 星形、白色整圆 | 5 |

- **随机都要带种子**（`FX.rng(seed)`）：同样的参数永远得到同样的帧，才能逐版对比，也能做回归检查。
- **方向用分层抽样**（`FX.stratified`）：把一圈均分成 n 份，每份里随机偏一点。完全随机的方向会扎堆，火球就歪了。

### 3. 运动

- `FX.integrate(元素, 经过的秒数, { drag, buoy, grav })`：用 1/120 秒的固定步长积分。
  - 阻力让初速度很快衰减，形成先快后慢的效果；
  - 浮力让烟往上飘；
  - 想加风、加旋转，在循环里多加一行力就行。
- `FX.ballistic`：火花用的闭式解，计算量更小。

### 4. 着色：平涂圆，每个烟团单独冷却

这一步决定像不像像素画。

- **每个烟团有自己的热度**，按指数冷却：`heat × e^(−(t − hold) / tau)`。不同烟团的 `tau` 不同，所以同一帧里黄的、红的、灰的烟团同时存在，有层次。
- **热度对应调色板的一档**。每个烟团只用三个颜色（`FX.puff`）：
  - 底色；
  - 左上偏移的亮圆，比底色高一档；
  - 右下的暗月牙，比底色低一档。
- **新烟黑，旧烟淡**：刚冷却成烟的烟团用暗的三色，再冷一些换成浅的三色。

下面两种做法都试过，都不要用：
- **写实的球面光照**：4 档平滑明暗，看起来是一堆石头。
- **整体温度场**（把所有烟团的温度加在一起再上色）：中心一大片温度相同，会一起变色，冷却时成了一整块均匀的红盘，像一个洞。

### 5. 顺序和分层

- **绘制顺序在生成时定好**（按 z），之后不再变。如果每帧按会变化的值（比如温度）重新排序，元素会前后乱跳。
- **分层画，分层清理**：`FX.clean` 只用在烟团层上，用来去掉细刺、碎块和孤点。火花、余烬、描边本来就只有 1 像素宽，不能一起清理。

### 6. 消散

- **形状**：烟团在寿命末尾一边缩小，一边被一个从侧面长大的圆“咬”掉，剩下的月牙越来越细，直到消失。
- **方向**：咬的方向统一偏下。烟往上飘，底部先散，上面留下圆顶。
- **清理**：之后 `FX.clean` 依次做四件事：
  1. 开运算，去掉不到 3 像素宽的尖角；
  2. 去掉小于 6 像素的碎块；
  3. 填上小洞；
  4. 把孤立的单个像素改成邻居的颜色。

### 7. 检查（每一版都做）

1. **读数字**：每帧一行，依次是像素数、各颜色组的像素数、孤点、贴边像素、包围盒和覆盖条。
   - 覆盖条应该在 2~3 帧内冲到顶，之后慢慢下降；
   - `edge` 必须是 0，不是 0 说明特效被画布切掉了；
   - `lonely` 应该接近 0，它只统计清理后的烟团层，描边要加在副本上（见 `template.js`）；
   - 火的像素数应该逐帧减少，烟的像素数相应增加。
2. **看 `sheet.png`**：逐帧看形状和颜色，把问题写成具体的修改，例如“第 6~10 帧中间是一整块红色”“第 2 帧火球上有划痕”。
3. **看 `backgrounds.png`**：暗、中、亮三种背景都要看。浅色的东西（冲击波、白烟、白色闪点）在亮背景上会消失，只看暗背景发现不了。
   - 解决办法：加一圈深色描边（生成器里用 `--set outline=#2b2f6b`），用双色，或者让最暗的一档足够暗。
4. **看 `sizes.png`**：1 倍下各个阶段还能不能认出来。
5. **换两三个种子**（`--seed`）：确认不是碰巧只有一个种子好看。

文档里写的每个参数组合都要实际跑过、看过。比如单独把冲击波压扁，它会藏在火球后面，只露出两侧两小段弧线；要同时把它挪到火球底部，才像地面冲击波。

这次实际遇到的问题，按“看到什么 → 原因 → 怎么改”整理如下：

| 看到的问题 | 原因 | 怎么改 |
|---|---|---|
| 火球歪成一条斜长条 | 方向完全随机，扎堆 | 分层抽样 |
| 每个烟团都是同心圆，像靶子 | 颜色只跟到圆心的距离有关 | 改成平涂圆 + 亮圆 + 暗月牙 |
| 火球一开始就裹着一层灰壳 | 温度在每个烟团边缘都降到 0 | 每个烟团按自己的热度整体上色 |
| 冷却时中间一整块红盘，像个洞 | 用了整体温度场，一起降温 | 每个烟团单独冷却，tau 各不相同 |
| 烟像石头 | 写实的球面光照 | 每个烟团只用三色 |
| 烟雾正中有一颗单独的红球 | 核心烟团冷却最慢、又在最前面 | 让它和其他烟团同步冷却，往后放 |
| 消散时满屏碎点 | 侵蚀噪声频率太高 | 改成缩小 + 咬成月牙，再清理 |
| 月牙像钩子、爪子 | 咬得太狠，尖角太细 | 咬圆半径 2r → 1.2r，开运算去细刺 |
| 火球表面有白色划痕 | 火花从中心出发，却画在火球上面 | 火花画在烟团后面 |
| 第 1 帧火球缺一块 | 烟团还没长齐，露出了背景 | 第 1 帧用白色整圆 |
| 亮背景上看不见冲击波 | 浅黄色，和背景太接近 | 双色环：外圈浅黄、内圈橙 |
| 最后一帧还有一片烟，然后突然消失 | 时长是手定的 | 渲染到所有元素都消失为止 |
| 放大 2 倍后像一串气球 | 只放大了半径 | 加倍烟团数量，半径少放大 |
| GIF 比设计的慢 5% | GIF 时长以 1/100 秒计，1/15 秒被取整成 7 | 按累计时间取整（`pixel.js` 已处理） |

### 8. 导出

- **裁剪**：去掉首尾空帧，所有帧按同一个“并集包围盒”裁剪。这样爆炸中心在每一帧里位置不变，锚点写进 JSON。
- **在游戏里用**：把锚点对准爆炸位置，播放一次，不循环。
- **格式**：精灵表是 1 倍、透明背景；GIF 只用来预览，放在中等深度的背景上。
- **留下生成命令**：交付时把预设、种子和 `--set` 参数一起写下，以后改一个数字就能重新生成。

## 做别的特效

- **换颜色**：换 `fire`、`smoke`、`ringColours` 三组颜色就行，`magic` 预设就是这样做的。浅色配色要加描边，否则放在亮背景上会消失，`magic` 预设默认就带描边。
- **去掉火**：`dust` 预设的做法：
  - 热度设为 0；
  - 关掉闪光、冲击波、火花和余烬；
  - 方向限制在上半圈（`arc`），再压扁竖直速度（`squash`）。
- **地面爆炸**：把冲击波压扁并挪到火球底部：`--set ring.squash=0.35 --set ring.dy=14`。
- **更小**：`--scale 0.5` 得到 24×31 的小爆炸，1 倍下各阶段仍能认出来。
- **更大**：只用 `--scale 2` 会像一串气球。实测下面的组合更好，烟团加倍、半径只放大约 1.3 倍：
  ```bash
  node scripts/explosion.js out/big --scale 2 --set puffs.n=24 --set column.n=12 --set "puffs.r=[4,6.5]" --set "column.r=[3.5,5.5]" --set core.r=6
  ```
- **全新的特效**：复制 `template.js` 来改。它不到 60 行，演示了完整流程：生成元素 → 按时间渲染 → 清理 → 描边 → 读数字 → 导出检查图。
- **新元素**（比如飞出去的碎块）：在 `explosion.js` 的 `render()` 里加一层，按第 2 节的表决定画在第几层；画完同样要看数字和三张检查图。
- **循环特效**（篝火、烟囱）：这个生成器只做一次性的特效，循环特效没有实测过。可以试的思路：按固定周期发射元素，从一个完整周期之后开始取一整个周期的帧，首尾就能接上。

参数含义、预设取值和调参经验，见 `references/recipes.md`。
